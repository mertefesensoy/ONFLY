## 1. Problem / motivation

`LICENSE` carried the MIT text followed by a block of third-party terms.
GitHub could not detect the licence at all (NOASSERTION), because the file
was no longer the MIT text, and the block itself was wrong or incomplete: it
named two of MaleCNS's four parties, called the SoftFloat 2c derivatives BSD
when 2c is not BSD, and left out SoftFloat 2c itself, the Shiu et al. code,
the FlyWire-derived reference curve, and every tool the labs depend on. The
two derived SoftFloat 3e files that were not generated from upstream text
pointed to the BSD licence instead of reproducing it, which is what its first
condition requires of a source redistribution. Nothing checked any of this,
so it would drift again at the first renamed path.

## 3. Implementation approach

**One register, one machine-readable mirror, one check.** The register a
person reads is `THIRD_PARTY_NOTICES.md`. Its per-path mirror is `REUSE.toml`,
which `reuse lint` checks for completeness: every file must resolve to a
licence and a copyright line. `tools/lint_ntc.py` checks the register against
a component list held in code.

**`tools/lint_ntc.py` contract.** Input: the working tree. It reads `LICENSE`,
`THIRD_PARTY_NOTICES.md`, the two BSD-derived files and the two data notices,
and writes nothing. Output: exit 0 with one `ok` line; exit 1 with one line
per finding; exit 2 on an internal error. Five checks:
1. `LICENSE` opens with "MIT License" and nothing follows the final
   "SOFTWARE.".
2. The register names each component and each of its paths, and each tool.
3. Each listed path exists, so a rename fails the check.
4. Both BSD-derived files carry the conditions and the disclaimer.
5. Both data notices exist.

It was written test-first. The self-test builds a good synthetic tree and
twelve single-fault variants in a temporary directory: 13 checks in all, 0
failed. Against the tree as it stood before any notice existed, the check
exited 1 with 8 findings.

**`REUSE.toml` ordering.** When several annotations match a path, REUSE
applies the last one. So the catch-all MIT annotation comes first, and each
third-party or derived group follows it. Every annotation uses
`precedence = "override"`, so text inside a file that happens to look like a
licence tag cannot change the result. Spot-checked from `reuse spdx`:
* `acc4.json` resolves to `LicenseRef-FlyWire-Pending`;
* `acc3-srext.json` resolves to CC-BY-4.0;
* `data/g0/inventory.json` resolves to MIT;
* `softfloat/c2c/softfloat.c` resolves to `LicenseRef-SoftFloat-2c`;
* `onfprim.c` resolves to BSD-3-Clause;
* `onfflag.c` resolves to MIT;
* the SRS resolves to MIT AND `LicenseRef-FlyWire-Pending`.

**Verbatim text is copied by program, not retyped.**
* `derive3e.py` reads `COPYING.txt` when it generates its output.
* The 2c notice in the register and in `LICENSES/` is sliced out of
  upstream's `README.txt` and `bits32/softfloat.c` by script, and asserted
  equal to the source.
* `onfrpk.c`'s inserted header was checked to occur verbatim in upstream
  `s_roundPackToF64.c`: 1,820 bytes.

**External facts were read on the day.** A read-only research pass on
2026-09-25 read each upstream's own page for every tool's terms, FlyWire's
guidelines and citation table, the MaleCNS pages, IBM's trademark page and
the Linux Foundation's wording. The register states only what those pages
say. Where a page is silent, the register says so rather than guess:
* TK5 publishes no terms;
* GCCMVS's GPL version is not stated;
* FlyWire's page does not name snapshot 630;
* no terms were found for Raincode's QIX runtime.

## 5. Design decisions

* **A component list in code, not parsed from the register** (engineer, P-43):
  the check must fail when the register drops something, so the list it
  checks against cannot come from the register.
* **`reuse lint` outside `make test`** (P-43): `reuse` is not a declared
  dependency until slice E's `requirements.txt`; it was installed pinned
  into the session's scratch directory (D-521) and run by hand.
* **FlyWire as `LicenseRef-FlyWire-Pending`** (P-43, D-515): an SPDX
  identifier for a real licence would have taken the position D-515 declined.
  The LicenseRef text is a status notice and says it grants nothing.
* **`data/g0/` is not MaleCNS-derived.** P-43's Section 1 listed it under
  MaleCNS. Reading `inventory.json` showed it holds only host, MVS, s390x
  and x86 environment facts, so the register and the check omit it, and it
  falls under the catch-all MIT annotation. This corrects the engineer's own
  plan; no owner decision changed.
* **`generated/onftfv.h` as BSD-3-Clause**, following P-41 C3: the file holds
  TestFloat's output, and treating it as TestFloat-licensed is the cautious
  reading. It is not a legal position.
